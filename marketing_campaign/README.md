# Chiến dịch Marketing Affiliate trên Threads

## Cấu trúc thư mục lưu trữ
- `01_product_research/` — Bảng lọc sản phẩm dễ bán, dễ làm nội dung, hoa hồng cao (10%–20%).
- `02_content_bank/` — Kho Hook CTR cao, kịch bản 3 bước (Main Post → Reply Link → Reply Tương tác).
- `03_creatives/` — Prompt tạo ảnh/video review và thư viện hình ảnh sản phẩm.
- `04_affiliate_links/` — Quản lý link Affiliate gốc và quy chuẩn gắn UTM đo lường.
- `05_analytics_reports/` — Theo dõi CTR, lượng click, đơn hàng và tối ưu A/B Hook theo tuần.
